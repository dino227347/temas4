⭐ Resumen Rápido

Polinomio: expresión algebraica formada por la suma finita de monomios (productos de variables y constantes).

  • Grado: mayor exponente de la variable.
  • Tipos: grado cero, primer grado, segundo grado, tercer grado, cuarto grado, nulo, homogéneo, heterogéneo, completo, ordenado, iguales, semejantes.
  • Valor numérico: resultado al sustituir la variable por un número.
  • Suma: se suman los coeficientes de términos del mismo grado.
  • Resta: se suma el opuesto del sustraendo.
  • Multiplicación: se multiplica cada término del primero por cada término del segundo; se suman los términos semejantes.
  • División: se divide el primer término del dividendo entre el primer término del divisor; se multiplica y resta; se repite hasta que el grado del residuo sea menor que el del divisor.

1. Introducción

Un polinomio es una expresión algebraica constituida por una suma finita de productos entre variables (valores desconocidos) y constantes (coeficientes). Las variables pueden tener exponentes naturales (incluido el cero). El valor máximo de estos exponentes se conoce como el grado del polinomio.

Los polinomios son objetos fundamentales en matemáticas y ciencia. Se utilizan para aproximar funciones, en ecuaciones polinómicas y funciones polinómicas con aplicaciones en física, química, economía y ciencias sociales. En álgebra abstracta, los polinomios construyen los anillos de polinomios, un concepto central en teoría de números y geometría algebraica.

Este tema tiene como objetivos:

  • Realizar con destreza operaciones entre expresiones algebraicas.
  • Aplicar con soltura las herramientas matemáticas adquiridas.

2. Polinomios

Polinomio: expresión algebraica de la forma:

P(x) = anxn + an−1xn−1 + ... + a1x + a0

Donde an, an−1, ..., a1, a0 son los coeficientes (números reales) y x es la variable. El término a0 se llama término independiente.

Ejemplo: P(x) = 5x4 − 3x3 + 2x2 + 7x + 6

Coeficientes: 5, −3, 2, 7, 6. Término independiente: 6.

Los polinomios pueden tener una o más variables. Si tienen una sola variable, se llaman polinomios en una variable.

2.1 Grado de un polinomio

Grado de un polinomio: es el mayor exponente al que se encuentra elevada la variable.

Ejemplo: P(x) = x4 + 3x3 + 12x2 + 7x + 16 → grado 4.

Si el polinomio tiene varias variables, el grado es la suma de los exponentes de cada término, tomando el mayor valor.

Ejemplo: P(x, y) = 2x2y3 + 5xy2 − 3y4 → grado absoluto = 2+3 = 5.

2.2 Tipos de polinomios

Por grado

  • Grado cero: P(x) = 2 (constante).
  • Primer grado: P(x) = 3x + 2 (lineal).
  • Segundo grado: P(x) = 2x2 + 3x + 2 (cuadrático).
  • Tercer grado: P(x) = x3 − 2x2 + 3x + 2 (cúbico).
  • Cuarto grado: P(x) = x4 + x3 − 2x2 + 3x + 2 (cuártico).

Por estructura

  • Polinomio nulo: todos los coeficientes son cero. Ej: P(x) = 0x3 + 0x2 + 0x + 0.
  • Polinomio homogéneo: todos los términos tienen el mismo grado. Ej: P(x,y) = 2x2 + 3xy − 10y2 (todos grado 2).
  • Polinomio heterogéneo: los términos tienen distinto grado. Ej: P(x) = 2x3 + 3x2 − 3.
  • Polinomio completo: tiene todos los términos desde el término independiente hasta el de mayor grado. Ej: P(x) = 2x3 + 3x2 + 5x − 3.
  • Polinomio ordenado: los monomios están escritos de mayor a menor grado. Ej: P(x) = 2x3 + 5x − 3.

Por comparación

  • Polinomios iguales: mismo grado y mismos coeficientes para términos del mismo grado. Ej: P(x) = 2x3 + 5x − 3 y Q(x) = 2x3 + 5x − 3 son iguales.
  • Polinomios semejantes: tienen la misma parte literal (mismas variables con los mismos exponentes). Ej: P(x) = 2x3 + 5x − 3 y Q(x) = 5x3 − 2x − 7 son semejantes.

2.3 Valor numérico de un polinomio

Valor numérico: es el resultado que se obtiene al sustituir la variable por un número determinado y realizar las operaciones.

Ejemplo: P(x) = 2x3 + 5x − 3. Para x = 2:

P(2) = 2(2)3 + 5(2) − 3 = 16 + 10 − 3 = 23

2.4 Suma de polinomios

Suma de polinomios: se suman los coeficientes de los términos del mismo grado.

Ejemplo: P(x) = 2x3 + 5x − 3 ; Q(x) = 4x − 3x2 + 2x3

  1. Ordenar Q(x): Q(x) = 2x3 − 3x2 + 4x
  2. Sumar: P(x) + Q(x) = (2x3 + 5x − 3) + (2x3 − 3x2 + 4x)
  3. Agrupar términos semejantes: (2x3 + 2x3) − 3x2 + (5x + 4x) − 3
  4. Resultado: P(x) + Q(x) = 4x3 − 3x2 + 9x − 3

2.5 Resta de polinomios

Resta de polinomios: consiste en sumar el opuesto del sustraendo.

Ejemplo: P(x) = 2x3 + 5x − 3 ; Q(x) = 4x − 3x2 + 2x3

  1. Ordenar Q(x): Q(x) = 2x3 − 3x2 + 4x
  2. Restar: P(x) − Q(x) = (2x3 + 5x − 3) − (2x3 − 3x2 + 4x)
  3. Distribuir el signo negativo: 2x3 + 5x − 3 − 2x3 + 3x2 − 4x
  4. Agrupar: (2x3 − 2x3) + 3x2 + (5x − 4x) − 3
  5. Resultado: P(x) − Q(x) = 3x2 + x − 3

2.6 Multiplicación de polinomios

a) Número por polinomio

Se multiplica el número por cada coeficiente del polinomio. El grado se mantiene.

Ejemplo: 3·(2x3 − 3x2 + 4x − 2) = 6x3 − 9x2 + 12x − 6

b) Monomio por polinomio

Se multiplica el monomio por cada término del polinomio.

Ejemplo: 3x2·(2x3 − 3x2 + 4x − 2) = 6x5 − 9x4 + 12x3 − 6x2

c) Polinomio por polinomio

Se multiplica cada término del primer polinomio por todos los términos del segundo. Luego se suman los términos semejantes. El grado del producto es la suma de los grados de los polinomios factores.

Ejemplo: P(x) = 2x2 − 3 ; Q(x) = 2x3 − 3x2 + 4x

  1. Multiplicar: (2x2 − 3)·(2x3 − 3x2 + 4x) = 4x5 − 6x4 + 8x3 − 6x3 + 9x2 − 12x
  2. Sumar términos semejantes: 4x5 − 6x4 + 2x3 + 9x2 − 12x

2.7 División de polinomios

División de polinomios: operación que obtiene un cociente (C) y un residuo (R) a partir de un dividendo (D) y un divisor (d). Si R = 0, la división es exacta.

Pasos:

  1. Ordenar el dividendo y el divisor de mayor a menor grado. Completar con ceros los términos faltantes.
  2. Dividir el primer término del dividendo entre el primer término del divisor → primer término del cociente.
  3. Multiplicar este término por todo el divisor y restar del dividendo.
  4. Repetir el proceso con el nuevo dividendo hasta que el grado del residuo sea menor que el grado del divisor.

Ejemplo: Dividir P(x) = x5 + 2x3 − x − 8 entre Q(x) = x2 − 2x + 1

        x⁵ + 2x³ - x - 8   |  x² - 2x + 1
        -x⁵ + 2x⁴ - x³     |  x³ + 2x² + 5x + 8
        ──────────────────
             2x⁴ + x³
            -2x⁴ + 4x³ - 2x²
            ──────────────────
                  5x³ - 2x²
                 -5x³ +10x² -5x
                 ──────────────────
                       8x² - 6x
                      -8x² +16x -8
                      ──────────────────
                            10x - 16

Cociente: C(x) = x3 + 2x2 + 5x + 8

Residuo: R(x) = 10x − 16

Comprobación: D = d·C + R

3. Ejercicios resueltos

Ejercicio 1: Realizar las siguientes operaciones:

a) (8x² − 2x + 1) − (3x² + 5x − 8)

👆 Ver solución
= 8x² − 2x + 1 − 3x² − 5x + 8
= 5x² − 7x + 9

Ejercicio 2: (2x³ − 3x² + 5x − 1) − (x² + 1 − 3x)

👆 Ver solución
= 2x³ − 3x² + 5x − 1 − x² − 1 + 3x
= 2x³ − 4x² + 8x − 2

Ejercicio 3: Dados P(x) = −7x⁴ + 6x² + 6x + 5, Q(x) = −2x² + 2 + 3x⁵, R(x) = x³ − x⁵ + 3x², calcular:

a) P(x) + Q(x)

👆 Ver solución
= (−7x⁴ + 6x² + 6x + 5) + (−2x² + 2 + 3x⁵)
= 3x⁵ − 7x⁴ + 4x² + 6x + 7

Ejercicio 4: P(x) − Q(x)

👆 Ver solución
= (−7x⁴ + 6x² + 6x + 5) − (−2x² + 2 + 3x⁵)
= −7x⁴ + 6x² + 6x + 5 + 2x² − 2 − 3x⁵
= −3x⁵ − 7x⁴ + 8x² + 6x + 3

Ejercicio 5: P(x) + Q(x) + R(x)

👆 Ver solución
= (−7x⁴ + 6x² + 6x + 5) + (−2x² + 2 + 3x⁵) + (x³ − x⁵ + 3x²)
= 2x⁵ − 7x⁴ + x³ + 7x² + 6x + 7

Ejercicio 6: Multiplicar: −3ab·(7a² − 5ab³)

👆 Ver solución
= (−3ab)·(7a²) + (−3ab)·(−5ab³)
= −21a³b + 15a²b⁴

Ejercicio 7: Dividir: (x³ − x² − 42x) / (x − 6)

👆 Ver solución 
        x³ - x² - 42x   |  x - 6
        -x³ + 6x²       |  x² + 5x
        ───────────────
             5x² - 42x
            -5x² + 30x
            ───────────
                 -12x
                 +12x - 72
                 ─────────
                       0

C(x) = x² + 5x + 12, R(x) = 0

Ejercicio 8: Dividir: (x⁴ + 1) / (x − 1)

👆 Ver solución 
        x⁴ + 0x³ + 0x² + 0x + 1   |  x - 1
        -x⁴ + x³                  |  x³ + x² + x + 1
        ──────────────────────────
             x³ + 0x² + 0x + 1
            -x³ + x²
            ─────────────────────
                 x² + 0x + 1
                -x² + x
                ────────────────
                     x + 1
                    -x + 1
                    ─────────
                        2

C(x) = x³ + x² + x + 1, R(x) = 2
